# Module Federation — Visual Knowledge Base

תשתית ידע חזותית לקראת דמו של פורטל מודולרי. **זהו שלב תכנון בלבד; הדמו טרם מומש.**

## התיעוד

- [מפת הידע האינטראקטיבית](docs/index.html) — מטרות, טכנולוגיות, טעינה, monorepo, הרשאות ושאלות פתוחות.
- [טיוטת Blueprint](docs/blueprint.md)
- [יומן החלטות](docs/decisions.md)

## תצוגה בדפדפן

קובץ `docs/index.html` עצמאי: אפשר להוריד ולפתוח בדפדפן, ללא התקנת חבילות. GitHub מציג HTML כקוד; תצוגה באתר מחייבת הפעלת GitHub Pages.

## סטטוס מימוש

אין עדיין Shell, remotes, backend או פקודות התקנה/הרצה של הדמו. עץ apps/packages המופיע בתיעוד הוא הצעה בלבד. ההדגמות האינטראקטיביות באתר הן כלי הסבר, לא מימוש Module Federation.

כל הדוגמאות סינתטיות. אין נתוני לקוחות או פרטי גישה.
