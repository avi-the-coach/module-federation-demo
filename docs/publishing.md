# הפעלת GitHub Pages

קובצי האתר נמצאים ב־`docs/` בענף `main`. האתר הוא HTML סטטי, ללא build וללא חבילות.

## הגדרה חד־פעמית
1. פתחו את ה־repository ב־GitHub עם חשבון בעל הרשאת ניהול.
2. Settings → Pages.
3. תחת Build and deployment בחרו Source: **Deploy from a branch**.
4. בחרו branch: **main**, folder: **/docs**, ולחצו Save.
5. המתינו לבנייה/פריסה. GitHub יציג את כתובת האתר כאשר יהיה מוכן.

אל תסיקו שהאתר פורסם רק מכך שהקבצים קיימים. יש לוודא ש־Pages מציג פריסה מוצלחת ולפתוח את כתובת האתר. אין בתיעוד הזה הוראות התקנה או הרצה לדמו — הוא עדיין לא מומש.
